## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+ and npm

### Clone & Install

```bash
git clone https://github.com/Adi432144/my-portfolio.git
cd my-portfolio
npm install
```

### 🔥 Run the dev server

```bash
npm run dev
```
Hot-reloading dev server at `http://localhost:5173`

### 📦 Build for production

```bash
npm run build
```
Outputs an optimized static build to `dist/`

### 👀 Preview the production build

```bash
npm run preview
```

### 🧹 Lint

```bash
npm run lint
```

## ☁️ Deployment

Deployed on **[Vercel](https://vercel.com/)**, which auto-detects the Vite preset:

| Setting | Value |
|---|---|
| Framework | Vite |
| Build Command | `vite build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

Every push to `main` triggers an automatic redeploy. ✅
